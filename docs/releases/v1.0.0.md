## Azadi Connect 1.0.0 · آزادی کانکت

A bilingual Windows VPN client with selected-application and entire-system routing.

### What's included

- In-app stable release checks, download progress, SHA-256 verification and an explicit install action.
- Session disconnect timers (15, 30, 60 or 120 minutes).
- Queued, dismissible notifications with screen-reader announcements.
- Safer profile and network-protection controls, plus persistent connection diagnostics.
- Bilingual documentation and regression coverage.

### Download and upgrade

Download **Azadi-Connect-1.0.0-Windows-x64-Setup.exe** and compare its hash with **SHA256SUMS.txt**. Close the old app before upgrading. Existing encrypted profiles are preserved.

Version 0.4.1 does not have the new updater: install 1.0.0 manually once. Version 1.0.0 can retrieve subsequent stable releases from Settings → Update center without visiting GitHub.

### Important limits

Windows 10/11 x64 only. This release is unsigned: Windows may show an unknown-publisher warning. SHA-256 is an integrity check, not publisher code signing or an independent security audit. Bring your own valid VPN profile.

Automatic disconnect does not release a persistent Kill Switch. Use **Restore direct Internet** to remove protection explicitly.

The release workflow validates unit/UI tests, native helpers, generated engine configurations, Windows routing/WireGuard, package integrity and installation before uploading these assets. Provider compatibility still depends on your network and server.

The pinned sing-box source archive and Wintun license are included for third-party license compliance.
